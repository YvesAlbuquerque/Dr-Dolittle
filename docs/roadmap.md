# Research roadmap

This is an evidence-gated plan, not a delivery commitment.

| Phase | Goal | Exit evidence | Status |
| --- | --- | --- | --- |
| R0 | Publish scope, ontology proposal, contribution process | Reviewable public documents | Documented |
| R1 | Literature-backed definitions and claim taxonomy | Critically read sources, operational definitions and unresolved disagreements | Prototyped (80-reference catalog, 15 unreviewed source observations and draft coverage chart; definitions and claims still unvalidated) |
| R1-P | Evaluate physiological biomarkers, cross-species molecular homology, assay timescale and neural/behavioral links to communication | Source-linked candidate measurements, explicit confounders and review | Scaffolded (documentation and empty fields only) |
| R1-AI | Design an AI-operated research pipeline with source integrity screening and evidence-grounded model critiques | Architecture, staged source integrity records, conjecture ledger and validator; no autonomous model run or calibration | Scaffolded |
| R1-C | Methodologically appraise source-specific observations and synthesize explicit hypothesis-level certainty | 15 not-assessed placeholders, evidence-confidence protocol and validators; no graded hypotheses yet | Scaffolded |
| R2 | Group-level comparative evidence matrix | Traceable study-to-capability entries and confidence labels | Planned |
| R3 | Select high-information comparisons and candidate species | Transparent selection criteria and dataset audits | Planned |
| R4 | Reproducible baseline computational experiments | Data permissions, code, evaluation splits, measured results | Planned |
| R5 | Expand atlas and test cross-group predictions | Independent replication or falsification attempts | Planned |

## Good first contributions

- Propose a clearer operational definition with peer-reviewed references.
- Identify a missing communication modality or a category overlap.
- Add a well-supported group-level example and its limitations.
- Document a counterexample to an assumed universal capability.
- Compare candidate datasets' provenance, licensing, and synchronization.
- Review the evidence-state vocabulary for ambiguity.

Before opening a large implementation PR, discuss the research question and acceptance criteria in an issue. The [R1 pilot](r1-pilot-01.md), [foundation audit](foundation-audit-2026-11-23.md), [reading queue](references.md), [related projects](related-projects.md) and [instrumentation decision](research-instrumentation.md) establish the R1 foundation, **not** the scientific exit criteria.
