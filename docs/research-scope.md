# Research questions and scope

**Status: Proposed — conceptual research framework, not a validated scientific model.**

## Central question

Can animal communication systems be compared using a shared, evidence-grounded set of structural, sensory, social, and pragmatic capabilities, without assuming that human language is their inevitable evolutionary destination?

## Research questions

1. What observable properties distinguish communicative signals from incidental cues and other information-bearing phenomena?
2. Which dimensions allow meaningful comparison across modalities and taxonomic groups?
3. Which capabilities appear conserved, specialized, independently evolved, or lost?
4. Can similarities between systems generate testable predictions about understudied groups?
5. Where can multimodal machine learning help discover patterns without prematurely attributing meaning?

## Working hypothesis

Partly shared dimensions of communication can be mapped across animal groups. Combining these comparisons with phylogenetic, ecological, and behavioral evidence may reveal patterns of conservation, convergence, and innovation. Similarity alone does **not** establish shared evolutionary origin, equivalent cognition, intention, or semantics.

## Scope boundaries

**In scope:** comparative classification of communicative phenomena; modalities; signal structure; context and response; capabilities; group-level comparisons; evidence provenance; eventually targeted species-level empirical studies.

**Supporting evidence only:** interspecies communication, when it illuminates a capability or a receiver's interpretation. It is not a parallel comprehensive research program.

**Not initial objectives:** animal-to-human translation, universal emotion decoding, ranking species by intelligence, a complete origin-of-language theory, or claims that an ML cluster is a meaningful word.

## Humans as a reference case

Human spoken, signed, gestural, prosodic, and contextual communication provides rich positive controls for particular capabilities. Human language must not be treated as a universal template or endpoint. Comparisons should specify exactly which capability is being tested.

## Critical distinctions

- **Signal vs cue:** a cue can convey information without having evolved for communication.
- **Form vs function vs meaning:** an acoustic class, a behavioral consequence, and a semantic interpretation are different kinds of claims.
- **Observation vs inference:** inferred cognitive states require independent support.
- **Unknown vs absent:** insufficient research cannot justify coding a capability as absent.
- **Communication similarity vs phylogenetic relatedness:** evolutionary history requires phylogenetic evidence.

## Potential outputs

A documented ontology, a versioned evidence matrix, a comparative capability atlas, and eventually reproducible experiments. These are planned directions, not completed artifacts.
